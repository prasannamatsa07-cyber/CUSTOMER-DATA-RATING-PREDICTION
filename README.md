# 🛒 E-Commerce Customer Behaviour — Customer Rating Predictor

A complete end-to-end **Machine Learning web application** built with Python,
scikit-learn, and Streamlit that predicts a customer's **rating (1–5 ⭐)**
for an e-commerce order based on order and session features.

---

## 📂 Project Structure

```
customer-behaviour/
├── app.py                  ← Streamlit web application
├── train_model.py          ← Model training & evaluation script
├── requirements.txt        ← Python dependencies
├── README.md               ← This file
├── agent_instructions.md   ← AI agent / developer notes
├── .env.example            ← Environment variable template
├── data/
│   └── dataset.csv         ← E-commerce customer behaviour dataset
└── models/
    └── model.pkl           ← Trained ML pipeline (generated by train_model.py)
```

## 📊 Dataset

| Column | Type | Description |
|---|---|---|
| Age | Numeric | Customer age |
| Gender | Categorical | Male / Female / Other |
| City | Categorical | Turkish city |
| Product_Category | Categorical | Electronics, Fashion, etc. |
| Unit_Price | Numeric | Price per unit (₺) |
| Quantity | Numeric | Units purchased |
| Discount_Amount | Numeric | Discount applied (₺) |
| Total_Amount | Numeric | Final order total (₺) |
| Payment_Method | Categorical | Credit Card, Debit Card, etc. |
| Device_Type | Categorical | Mobile / Desktop / Tablet |
| Session_Duration_Minutes | Numeric | Minutes spent on site |
| Pages_Viewed | Numeric | Number of pages visited |
| Is_Returning_Customer | Boolean | 1 = returning, 0 = new |
| Delivery_Time_Days | Numeric | Days to deliver |
| **Customer_Rating** | **Target** | **1 – 5 (classification)** |

## 🚀 Quick Start (Local)

### 1. Clone / set up the repository

```bash
git clone https://github.com/<your-username>/customer-behaviour.git
cd customer-behaviour
```

### 2. Create a virtual environment (recommended)

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Train the model

```bash
python train_model.py
```

This will:
- Load `data/dataset.csv`
- Train and compare 5 classifiers (Random Forest, Gradient Boosting, Extra Trees,
  Logistic Regression, KNN)
- Save the best pipeline to `models/model.pkl`

### 5. Launch the Streamlit app

```bash
streamlit run app.py
```

Open [http://localhost:8501](http://localhost:8501) in your browser.

## ☁️ Streamlit Community Cloud Deployment

1. Push the repository to GitHub (include `data/dataset.csv` and `models/model.pkl`).
2. Go to [share.streamlit.io](https://share.streamlit.io) → **New app**.
3. Select your repo, branch `main`, and set `app.py` as the entry point.
4. Click **Deploy** — Streamlit Cloud will install `requirements.txt` automatically.

> **Tip:** commit `models/model.pkl` to the repo so Streamlit Cloud does not need
> to re-train on startup.  Alternatively, add a `[tool.streamlit] run = "python train_model.py"` 
> step or use Streamlit's `on_start` hooks if you prefer to train on deploy.

## 🤖 ML Details

| Item | Value |
|---|---|
| Problem type | Multi-class Classification |
| Target column | `Customer_Rating` (1–5) |
| Models evaluated | Random Forest, Gradient Boosting, Extra Trees, Logistic Regression, KNN |
| Selection criterion | Highest test-set accuracy |
| Preprocessing | Median imputation + StandardScaler (numeric), Most-frequent imputation + OrdinalEncoder (categorical) |
| Train / test split | 80 % / 20 % (stratified) |
| Cross-validation | 5-fold on training set |
