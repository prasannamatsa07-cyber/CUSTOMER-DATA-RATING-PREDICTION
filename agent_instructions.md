# Agent Instructions

## Project Overview
This repository contains a complete ML web application that predicts
**Customer Rating (1–5)** for e-commerce orders using the
`data/dataset.csv` dataset (E-Commerce Customer Behaviour).

## Key Files
| File | Purpose |
|---|---|
| `train_model.py` | Loads data, trains 5 classifiers, saves best pipeline to `models/model.pkl` |
| `app.py` | Streamlit UI — loads `model.pkl`, collects feature inputs, returns prediction |
| `requirements.txt` | All Python dependencies |
| `data/dataset.csv` | Raw dataset (do **not** modify) |
| `models/model.pkl` | Serialised sklearn Pipeline (generated by `train_model.py`) |

## Dataset Schema
Target column: `Customer_Rating` (integer 1–5, classification)

Dropped columns (identifiers / temporal): `Order_ID`, `Customer_ID`, `Date`

Numeric features: Age, Unit_Price, Quantity, Discount_Amount, Total_Amount,
Session_Duration_Minutes, Pages_Viewed, Is_Returning_Customer, Delivery_Time_Days

Categorical features: Gender, City, Product_Category, Payment_Method, Device_Type

## Workflow
1. Run `python train_model.py` → produces `models/model.pkl`
2. Run `streamlit run app.py` → opens prediction UI

## Conventions
- Use **relative paths** (`os.path.dirname(os.path.abspath(__file__))`) everywhere.
- No hard-coded predictions; all predictions come from `pipeline.predict()`.
- No API keys required; `.env.example` is provided for future extensions.
- Compatible with Python 3.9+, scikit-learn ≥ 1.4, Streamlit ≥ 1.32.

## Extending the App
- To add a new model: add it to the `CANDIDATES` dict in `train_model.py`
  and re-run the training script.
- To add new features: update `DROP_COLS`, re-run training, then update the
  `FRIENDLY_LABELS` dict in `app.py` with a user-facing label.
- To deploy: push to GitHub and connect to Streamlit Community Cloud.
  Make sure `models/model.pkl` is committed to the repo.
